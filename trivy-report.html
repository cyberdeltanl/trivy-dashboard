Trivy report viewer

Open one or more Trivy outputs: JSON from trivy k8s, image, fs or repo, or a CycloneDX or SPDX SBOM. You get worst images, unique CVEs with the images they affect, misconfigurations, secrets, licenses and packages, and can save the result as a single HTML report to share.

Producing input

# whole cluster (current kube context)
trivy k8s --report summary -f json -o cluster.json

# image or directory, with secrets, misconfigurations and licenses
trivy image --scanners vuln,secret,misconfig,license -f json -o image.json nginx:1.29
trivy fs --scanners vuln,secret,misconfig,license -f json -o fs.json .

# SBOMs and package inventories
trivy image --format cyclonedx --scanners vuln -o sbom.cdx.json nginx:1.29
trivy image --format spdx-json -o sbom.spdx.json nginx:1.29
trivy image -f json --list-all-pkgs -o packages.json nginx:1.29

              About this report

                What a scan does not show

                • Images Trivy could not pull. Workloads where every image failed are listed in the summary; a workload where only one of several containers failed looks normal here, so check the scan log for ERROR lines.
                • Java runtimes installed from tarballs (for example under /opt/java). Trivy detects a JDK only when it came from an OS package; JAR files are covered.
                • Containers outside Kubernetes, images that are not deployed, and node-level checks when the node collector is disabled.
